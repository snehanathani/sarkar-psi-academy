## 🚀 Custom Domain Setup (`www.sarkarpsiacademy.com`)

1. In the repository settings on GitHub, navigate to **Pages** -> **Custom domain**.
2. Enter `www.sarkarpsiacademy.com` (or `sarkarpsiacademy.com`).
3. In DNS records (GoDaddy / Cloudflare):
   - Add a `CNAME` record: Host `www` -> Points to `snehanathani.github.io`
   - Add `A` records for root domain pointing to GitHub Pages IPs:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
4. Toggle **Enforce HTTPS** in GitHub Pages settings.
